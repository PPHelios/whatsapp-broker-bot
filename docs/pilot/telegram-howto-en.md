# Broker welcome message on Telegram (pilot, English)

Send this to each English-speaking broker after running `scripts/onboard.js`, with their **Telegram start link** (printed by `onboard` when `telegram_bot` or `TELEGRAM_BOT_USERNAME` is set; one use, valid 7 days). Then send the website guide (`docs/pilot/web-howto-en.md`). Arabic version: `docs/pilot/telegram-howto-ar.md`. The WhatsApp version (`broker-howto-en.md`) is only for brokers who stay on the WhatsApp bot.

---

Hi 👋 this is *WehdatHub*, your inventory and clients assistant on Telegram (@Wehdat_Hub_bot). Messages to the bot are free.

*▶️ Start here*
Install Telegram if you don't have it, then tap your start link and press *Start*. If the link has expired, open the bot and tap *📱 Share my number* (it must be the number your agency registered).

*➕ Add a unit*
Type *add*, then send the photos and a voice note or a message with the details. Type *done* to see the review, then tap *Confirm & Save*. From WhatsApp, share a message, photo or voice note to Telegram (long-press → Share → Telegram → WehdatHub).

*🔍 Search*
Type or say: "3-bedroom apartment in New Cairo under 9M". You get 10 units per message; tap *More* for the rest.

*⚡ Quick updates*
• "sold VIL-08" · "available VIL-08" · "price VIL-08 9M" · "edit VIL-08"

*👤 Clients*
Share a client's message or contact card from WhatsApp, or type "lead Sara 0101…". Type *my leads* or *followups* any time. Reminders and alerts come here, free.

*📤 Sending to a client*
Send the code (e.g. *VIL-08*) and choose *Client copy*. Tap *📤 Send on WhatsApp* under it: WhatsApp opens with the text ready, then pick the client. For photos, open the unit on the website and tap *Send photos to a client*.

*🌐 Website*
Tap the *WehdatHub* button next to the message box: the website opens inside Telegram, already signed in. On another device, send *login* for a sign-in link.

Type *help* (or tap */* for the menu) any time. You can switch between Arabic and English on the website (عربي / English at the top).

The full guide to clients, follow-ups, deals and credits: `docs/pilot/crm-howto-en.md`.
