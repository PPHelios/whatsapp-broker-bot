# Broker welcome message (pilot, English)

Copy this message and send it to each English-speaking broker after running `scripts/onboard.js`, with their **start link** (printed by `onboard`) and then the website guide (`docs/pilot/web-howto-en.md`). The start link opens a chat with the bot with *help* already typed: the broker must send a first message before WhatsApp lets the bot reply. Arabic version: `docs/pilot/broker-howto-ar.md`.

---

Hi 👋 this is *AqarChat*, your inventory assistant on WhatsApp.

*▶️ Start here*
Tap your start link and press send (it says *help*). The bot answers with the list of commands.

*➕ Add a unit*
Type *add*, then send the photos and a voice note or a message with the details (place, area, bedrooms, price, down payment and installments, delivery, sea-facing/corner…). Type *done* to see the review, then tap *Confirm & Save*.

*🔍 Search*
Type or say: "3-bedroom apartment in New Cairo under 9M". Tap *More* for the rest of the results.

*⚡ Quick updates*
• "sold VIL-08": it disappears from search
• "available VIL-08": confirms it is still available
• "price VIL-08 9M"
• "edit VIL-08", then send the change and type *done*

*👤 Clients*
Forward a client's message or contact card, or type "lead Sara 0101…". Send a voice note like "Called Ahmed, he wants to view VIL-08 on Friday at 5" and the bot offers to log it. Type *my leads* or *follow-ups* any time.

*📄 For the client*
Send the code (e.g. *VIL-08*) and choose *Client copy* or *Flyer*. The client copy has a link to the unit's page, and you get an alert when the client opens it.

*🌐 Website*
Send *login* and you get a link to the AqarChat website (search, add, import, clients, deals). Details in the website guide.

Type *help* any time. The bot answers in English; you can switch to Arabic on the website (عربي at the top).
