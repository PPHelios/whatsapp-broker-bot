# WehdatHub bot commands

Generated from `domain/commandWords.js` (F15). Arabic words work in any spelling (أ/إ/آ/ا, ة/ه, ى/ي, tatweel, diacritics, Arabic or Latin commas); English is case-blind. Older words still work but are not shown.

## 🏠 Units

| Words | What it does |
|---|---|
| **إضافة** / **add** | New unit: send the photos and details (text or voice), then "done" |
| **تم** / **done** | Finish a draft or an edit and open the review card |
| `NH-V12` | The code alone: the unit's card |
| **تعديل** CODE / **edit** CODE | Edit a unit (you can write the change after the code) |
| **سعر** CODE 9.5M / **price** CODE 9.5M | Change the price |
| **بيع** CODE / **sold** CODE | Mark sold |
| **أرشيف** CODE / **archive** CODE | Archive (hidden from search) |
| **متاح** CODE / **available** CODE | Make it available again |
| **حذف** CODE / **delete** CODE | Delete a unit (after you confirm) |
| **صفقة** L-0042 CODE 8.5M / **deal** L-0042 CODE 8.5M | Record a deal and its commission |
| **تحديث** / **update** | Update a project or the catalogue (price rise, sold...) (managers) |
